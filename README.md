This repository contains **10 difficult-level Python programming case studies** selected from the prescribed list of 100 problems as part of the Activity-Based Learning (ABL) Assignment.

Each case study is documented and implemented using Python programming concepts covered in the prescribed syllabus.

## 📝 Contents of Each Case Study

Each case study includes the following components:

1. **Problem Statement** – Description of the given problem.
2. **Objectives** – Goals to be achieved.
3. **Assumptions** – Conditions considered while solving the problem.
4. **Algorithm** – Step-by-step procedure.
5. **Flowchart** – Visual representation of program logic.
6. **Pseudocode** – Structured representation of the solution.
7. **Python Source Code** – Implementation of the solution.
8. **Test Cases** – Different input scenarios and expected results.
9. **Output Screenshots** – Screenshots showing program execution.
10. **Conclusion** – Summary of the implementation and learning outcomes.

## 🚀 How to Run the Programs

**Step 1: Clone the repository**

```bash
git clone https://github.com/bharani-karini/python-activity.git
```

**Step 2: Navigate to the project directory**

```bash
cd python-activity
```

**Step 3: Execute any Python program**

For example:

```bash
python Python-case_study01.py
```

To execute another case study, replace the filename with the corresponding Python file.
